# 🏏 IPL Analytics Dashboard

An interactive **Power BI dashboard** that provides insights into IPL team performance, player statistics, match outcomes, and season trends through dynamic visualizations and KPIs.

## 📌 Features

- Team-wise performance analysis
- Top batsmen and bowlers statistics
- Match and venue insights
- Season-wise trends
- Interactive filters and slicers
- Key performance indicators (KPIs)

## 🛠️ Tools Used

- Power BI
- Excel / CSV
- DAX
- Data Cleaning & Transformation

## 📊 Key Metrics

- Total Matches
- Total Teams
- Top Run Scorer
- Top Wicket Taker
- Most Successful Team
- Win Percentage Analysis

## 📂 Dataset

Historical IPL data containing match details, player statistics, venues, and results.

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/IPL-Analytics-Dashboard.git
```

2. Open the `.pbix` file in **Power BI Desktop**.
